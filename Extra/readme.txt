# Table4U API

This project contains a predictive system to estimate how long a person will stay in a restaurant. 
It uses features such as the number of people, time of day, day of the week, and other temporal data to predict the visit duration in minutes. 

The main notebook `table4u_API.ipynb` demonstrates the data processing, automated feature engineering with Featuretools, and the training of an XGBoost Regressor model to achieve this.
Full project at https://github.com/Oised/Table-4U.git (Web application)
